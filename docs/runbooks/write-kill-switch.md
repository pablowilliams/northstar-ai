# Runbook: material-action kill switch

Trigger on any unauthorised write, approval-bypass signal, unexplained duplicate action, compromised tool credential or severity-one customer harm.

1. Incident commander disables execution at the tool gateway; read-only recommendation may remain if the threat is contained.
2. Revoke affected workload credentials and freeze approval-token issuance.
3. Preserve traces, canonical payloads, approval records and upstream API responses.
4. Identify affected cases by release, tool, identity and time window; reconcile against commerce ledgers.
5. Notify security, product, payments, consumer duty and privacy according to classification.
6. Compensate incorrect actions through a separately authorised process.
7. Re-enable only after cause, exposure, fix, regression evidence and accountable sign-off are recorded.

The service owner exercises this runbook quarterly. Time to disable writes is an operational KPI.
